# DropCluster

Drop Cluster can be used as a simple "priority menu" for varying screen sizes. It works like a `cluster` layout, but as the items wrap, they are hidden in a dropdown. The dropdown is triggered by a button with an icon.

A priority menu is a common pattern for responsive design, where the most important items are shown on larger screens, and less important items are hidden in a dropdown on smaller screens. So the "priority" of the items is determined by their order in the markup, with the most important items appearing first.

As with all components in this library the Drop Cluster does not use @media queries to alter layout based on screen size. See Intro Documentation for more information.

This library also tries not to rely on JavaScript for functionality. The Drop Cluster is pure HTML and CSS only.
