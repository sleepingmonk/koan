# The Switcher

>***Layouts are NOT components! They are only a demo of the layout primitive for Storybook.  To use layout primitives in your own templates simply use the appropriate CSS Classes.  See documentation for more details.***

The Switcher switches from a horizontal layout to a vertical layout at a given **measure**.

<details>
  <summary>Inherited CSS Variables:</summary>
  - `--measure`: The width of the containing `.switcher` element that triggers the switch.
  - `--gap`: The space between child elements.
</details>

*No media queries were used in the making of this layout.*
